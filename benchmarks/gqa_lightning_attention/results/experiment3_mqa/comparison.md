# Dense vs Lightning sparse GQA latency

Median milliseconds per attention-layer forward. Sparse includes indexer projections, scores and exact top-2048 selection.

Configuration 1: main **48Q/1KV**, indexer **4Q/1KV** | Configuration 2: main **64Q/1KV**, indexer **8Q/1KV**

BF16, TP=1, NVIDIA H200, shuffled 128-token pages. Decode uses CUDA graph replay. Prefill uses eager execution and measures a final chunk of **2,048 total new tokens across the batch**, not full-prompt latency. Planning and scheduler overhead are excluded.
